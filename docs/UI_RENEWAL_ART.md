# UI 翻新・美術抽象需求（蒔）

> 2026-11-09。描述「要什麼感覺、不要什麼」，不規定實作。實作邊界看 `docs/UI_RENEWAL_ARCHITECTURE.md`。
> 每一項視覺結果由主代理（或使用者）看實際畫面判斷，代理不能自評「已達成」。

## 1. 一句話

**把京都收進一只會呼吸的漆器文箱裡。** 手一靠近，金就醒過來；手一離開，它又安靜地沉回漆裡。

參照：德川美術館「初音蒔繪料紙箱」的肉合研出蒔繪：高蒔繪的隆起和研出蒔繪的平面在同一個面上並存，金粉時而浮出、時而沉入黑漆。

### 三個關鍵詞
1. **沉靜**：大面積是暗的、留白的。光是稀少的，所以珍貴。
2. **黏手**：光和物件要跟著手走，帶一點重量和餘韻，不是滑鼠移過就瞬間跳變。
3. **工藝的不完美**：金粉疏密不均、紙纖維看得見、霞帶邊緣有手繪的抖動。不要乾淨的向量漸層。

### 不要
- 全像卡、彩虹色帶、霓虹、玻璃擬態（FeralUI 的 Hologram 只借它「光跟著手」的手法，**不借它的彩虹**）。
- 彈跳得像玩具（回彈要小，像木蓋落定，不像果凍）。
- 背景比文箱還搶眼。
- 遊戲 UI 式的發光邊框、粗陰影。

## 2. 色彩

只用傳統色的語彙，晝、夜兩套。

| 角色 | 晝（暖日） | 夜（月光） |
| :-- | :-- | :-- |
| 底（紙、空間） | 生成色、鳥の子色：帶黃的和紙白 | 藍鼠、消炭：帶藍的深灰，不是純黑 |
| 漆 | 黒漆、溜色（透出一點朱的黑） | 黒漆，更深 |
| 主光 | 金：山吹茶～黄金，偏暖、低彩度 | 銀：銀鼠、月白，金退成暗金只做點綴 |
| 點綴（極少量） | 朱（印章、強調） | 朱更暗 |

- 金不能是 `#FFD700` 那種亮黃。它是「被漆吃掉一半」的金，飽和度低，亮部才偶爾閃一下。
- 全站的色彩只能從這張表延伸，元件裡不另外發明顏色。

## 3. 文箱

### 3.1 放大近觀
- **放大的目的是「欣賞工藝」**，不是看地圖。近觀時要看得到：梨地金粉的顆粒和疏密、切金的方塊邊、高蒔繪隆起的邊緣受光。
- 如果放大後只是把同一張圖拉糊，就失敗了。近觀必須多出細節（金粉變成一顆一顆，而不是一層黃）。
- 感覺像「拿起放大鏡湊近」：推近時帶一點慣性，停下時輕微落定。平移時像在漆面上滑動，碰到邊緣有柔軟的阻力。
- 放大狀態要有安靜的提示，讓人知道怎麼回去（例如角落一個小小的縮小符號），但不能遮住文箱。
- **點蓋開箱**：預設先退回全景再開蓋，讓開箱這個儀式保持完整構圖。

### 3.2 光澤
- 手指掠過時，光點跟著走，金粉一顆顆地閃，不是整片同時變亮。
- 光的餘韻：手停下或離開，光不是瞬間熄掉，而是約半秒慢慢沉回去。
- 高蒔繪（隆起）的光要硬一點、亮一點；研出（平面）的光要柔、要被漆膜包住。兩者在同一個畫面裡要能分辨。
- 閒置時，光像月光移過窗紙一樣緩慢掃過，週期要長（約 5 秒以上），不能讓人覺得在「跑動畫」。
- 月光模式：光是冷的銀，範圍更小，金只在最亮的瞬間透出來。

## 4. 首頁背景

現在的問題：文箱四周只有一層漸層，像擺在空白的攝影棚裡。

**目標：文箱像放在一幅繪卷或一間和室裡**，背景提供「場所感」，但永遠退在後面。

### 主元素：すやり霞（必做）
- 繪卷裡那種橫向、帶圓角的金霞帶，2～3 條，上下錯落，部分被畫面邊緣裁掉。
- 晝：淡金，像金泥刷在紙上，邊緣有刷痕、不平整。夜：淡銀，更透明。
- 霞帶不能穿過文箱的正後方中心，要繞在上下和左右邊緣，形成框景。

### 底層：和紙（必做）
- 底色上有極淡的纖維紋和顆粒，近看才發現。目的是消除數位漸層的「塑膠感」。
- 四角微微壓暗（像光從上方落在文箱上），引導視線到中央。

### 可選：微粒（做完上面兩項再評估）
- 月光：極稀疏的浮塵或光點，緩慢上升，像月光裡的灰塵。
- 晝：幾乎不用；之後可以接歲時記，依季節換成櫻瓣或楓葉，每次畫面上不超過 5 片。

### 可選：遠景
- 低對比的山脈剪影（東山連峰意象），只在畫面下緣，跟著手做非常小的視差（幾個像素）。

### 背景的禁區
- 對比度：背景最亮和最暗的差，不能超過文箱本身明暗差的三分之一。
- 不能有清楚的具象圖案和文箱搶主題（不畫寺廟、不畫人物）。
- 換函時背景不要跟著大幅變化；換晝夜時才換色。

## 5. 其他頁面

整體方向：**從「文箱」打開之後，就像在讀一卷書**。

- **名所目錄、御秘帖**：卡片像一張張料紙或短冊，紙上有淡淡的金砂子；手靠近時微微傾斜，一道柔光掠過（只在有滑鼠的裝置）。
- **書卷**：展開時要有紙的重量，先快後慢，最後輕輕定住；收卷相反。不要現在的「縮放淡入」。
- **詳細頁**（DetailView、地圖）：底色、字體、線條沿用同一套和紙與漆的語彙，但功能優先。地圖周邊不加裝飾。
- **按鈕和標籤**：像印章或題箋：細線框、小字距，被選中時是朱或金的細邊，不用色塊填滿。
- **字體**：題字 Shippori Mincho B1，內文 Noto Serif TC／JP（沿用現況）。字距寬鬆，行高大。

## 6. 動態

| 情境 | 感覺 | 參考強度 |
| :-- | :-- | :-- |
| 開蓋 | 木蓋提起，有重量，最後一點點落定 | 回彈很小 |
| 放大／縮小 | 湊近、退開 | 回彈很小 |
| 平移碰邊 | 柔軟的阻力 | 橡皮筋 |
| 換函 | 從架上抽出下一只 | 輕快，不回彈 |
| 卡片傾斜 | 紙被手風吹動 | 角度很小（≤ 6°） |

- 減少動態：保留所有光和材質，只拿掉位移和回彈，改成直接到位或淡入。

## 7. 判斷方式（給主代理）

每一版都要看：
1. 1440px 和 375px，晝、夜各一張完整首頁。
2. 文箱近觀的原尺寸截圖：金粉是否「一顆一顆」。
3. 一段連續畫面：手掠過、放開、閒置掃光。只看靜止圖抓不到「黏手」和「餘韻」。
4. 和初音蒔繪料紙箱的照片並排：是漆器，還是變成了全像卡或遊戲 UI？

只要有一項回答是「像全像卡、像遊戲、背景搶戲、放大變糊」，那一版就退回。
