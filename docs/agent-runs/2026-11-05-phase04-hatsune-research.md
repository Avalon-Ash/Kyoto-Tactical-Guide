1. [德川美術館：初音の調度](https://www.tokugawa-art-museum.jp/collections/初音の調度/)：1639 年千代姬婚禮調度，幸阿彌長重製作；以《源氏物語》初音、胡蝶等意匠構成的一套調度。應借鑑整套器物的共同視覺語言；不宣稱它是平安時期製品。

3. [德川美術館：初音蒔繪料紙箱](https://www.tokugawa-art-museum.jp/collections/初音蒔絵料紙箱/)：供收納書寫料紙，深被蓋造、蓋面倒角；和歌散布蓋面及側面。館方尺寸 14.2 × 45.4 × 35.8 cm。照片可見金褐地、連續山水、側壁、蓋縫與金具。**借鑑器形，不把它誤稱為館藏「初音文庫」，也不把它說成原本收納旅遊書卷。**
4. [德川美術館：初音蒔繪文箱](https://www.tokugawa-art-museum.jp/collections/初音蒔絵文箱/)：供傳送書狀，為較狹長的器形。網站「文庫」是使用者設定的收納隱喻，器形優先參考寬面的料紙箱。

## 技法與視覺辨識

| 技法 | 視覺特徵 | 本案轉譯與避免事項 |
|---|---|---|
| 梨地 | 不規則扁薄金屬粉藏在透漆下，細碎、有深淺；表面研磨平滑 | 細粒琥珀金底；不是表面砂紙，也不是每幀換位置的噪點 |
| 濃梨地 | 粉粒密度與覆蓋增加、金色更厚實 | 雲霞、地面疏密漸變；不只是把顏色變暗 |
| 刑部梨地 | 金箔底配較大不規則片粒，再覆梨地漆 | 粗片與細粒的尺度對比；不等同濃梨地，不做平均圓點 |
| 螺鈿 | 貝片的真珠層光澤，隨角度顯現不同色彩 | 局部有輪廓的貝片；虹彩限制在片內，不整張地圖彩虹化 |
| 切金／切銀 | 切成細條、方形等輪廓明確的金銀薄片 | 屋脊、欄杆與局部幾何細節；與隨機粉粒區別 |
| 平文 | 薄金屬板剪成紋樣、貼置後覆漆研出 | 較完整、邊界清楚的金銀紋樣；不等同平蒔繪 |
| 高蒔繪／肉合研出 | 盛起的形體，並與其他技法整合 | 東寺山石、屋簷與建築的層次來源；底地不整片抬升 |

「平紋」依使用者漆藝語境暫按「平文（ひょうもん）」理解。

來源：[梨地技法辭典](https://kotobank.jp/word/梨地-108067)、[刑部梨子地](https://kotobank.jp/word/刑部梨子地-3227693)、[京都工藝美術作家協會](https://kogei.kyoto/kogei/urushi.html)、[角萬漆器](https://kakuman.jp/pages/ryukyu-technique)。螺鈿與平文是使用者要求的設計材料，**未查證為上述初音料紙箱上的具體技法**。

## 首頁與資料的對應（設計方案，非已實作）

- **文庫蓋面 = 京都總覽**：保持固定視點與既有京都構圖、十一行政區、古地名、代表地標；加上可辨識的盒沿、倒角、厚度與接縫。梨地承接整個地景，避免黑底與孤立圖示。
- **圖上選區 = 選卷**：區界維持不可見的命中資料，不重現硬切亮面，不新增蒔繪／區界切換。滑過一區時底地與代表地標共同回應；僅東寺先製作立體樣板。
- **開蓋 = 進入資料**：點東寺／南區後，蓋沿抬起、陰影分離，露出內部並銜接南區書卷。先採提蓋式轉場，符合被蓋造參考；不預設西式鉸鏈。視點不旋轉、不自由環繞。
- **書卷 = 現有景點資料介面**：行政區為卷、分區為章、景點為條目。封題、紙色、卷緣提供意象；搜尋、篩選、導航仍直接可用，不逐一翻動八百個裝飾卷軸。筆數由現有資料衍生，不硬編碼 809。
- **返回 = 收卷合蓋**：保留區域與焦點，減少動態時直接切換。開盒不另加一道選單或阻擋操作的長動畫。
