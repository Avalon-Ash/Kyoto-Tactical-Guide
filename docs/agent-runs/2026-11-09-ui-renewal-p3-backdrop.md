## 第二版（使用者回饋：加動態、形狀太像膠囊、太淡、位置與數量不對）

| 回饋 | 修改 |
|---|---|
| 加動態 | 每條霞帶是獨立 sprite，用 Web Animations 的 `translateX` 左右飄移，幅度 `clamp(寬×0.08, 24, 60)`px、單程 24～36 秒、彼此錯相。由合成器執行，沒有 JS 逐格。減少動態、開卷、讀卷時暫停，合函後從原位續播 |
| 太像膠囊 | 每條改成 2～3 段圓端長帶的聯集，主帶上下錯開短帶，形成繪卷的段差和多個圓端；外框只留聯集外緣 |
| 太淡 | 金泥改成不透明繪製再整體套透明度（晝 0.58、夜 0.30），加上金泥積聚的濃淡斑、外框線、更密的砂子與切金 |
| 位置與數量 | 四個候選列，從左右邊緣交錯伸入；可以從文箱兩端後面穿過，帶出前後層次，但連同飄移都不能進入文箱中央 50% 寬度。頂列從右側進，避開左上印章；底列也從右側，避開左下說明文字 |

## 第三版（使用者回饋：可以再熱鬧一點）

- 霞帶候選列從 4 列增加到 6 列，最多 5 條；手機帶高改成 `min(高×0.085, 寬×0.12)`，所以 375px 能放 4 條（原本 3 條），桌機 5 條。
- 新增微粒（`particleSpecs()`，純資料可測）：暖日是切金金箔，邊落下邊旋轉，`rotateY` 翻面時看起來像金箔閃光；月光是發微光的銀色浮塵往上升。數量 `clamp(面積/16000, 16, 32)`，每顆 14～28 秒一輪，彼此錯相，由 Web Animations 驅動。減少動態時整個隱藏，開卷時跟霞帶一起暫停。
- 檢查：lint exit 0；strict exit 0（0/0）；同組 node 測試 43/43（背景 8 項，新增微粒 1 項，霞帶數量改成手機 ≥4、桌機 ≥5）；build exit 0，study 158.53 kB；`git diff --check` exit 0。
- 瀏覽器：375×812 月光、暖日都是 4 條霞帶加 16 顆微粒，20 個動畫都在跑；1440×900 是 5 條加 32 顆，37 個動畫在跑。減少動態時 0 個在跑、微粒隱藏，關掉後恢復。無主控台錯誤。
