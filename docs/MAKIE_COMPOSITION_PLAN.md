# 蒔繪盤構圖：在平面上做出深度、不留純白

2026-11-14，蒔。起因：使用者說「初音調度之所以是國寶，很大一部分是構圖：它在平面上做出了深度，幾乎沒有純粹的留白，整塊平面的視覺資訊密度都很高」。
本檔是企劃。地的材質見 `MAKIE_GROUND_PLAN.md`；本檔處理「蓋面上放什麼、放在哪裡」。

## 1. 初音的蓋面怎麼在平面上做出深度

依據：dig-it〈初音蒔絵文台・硯箱の拡大〉特寫、德川美術館料紙箱與文箱照片（`MAKIE_GROUND_PLAN.md` §0a），以及使用者 2026-11-14 給的岩與樹幹特寫。

| 手法 | 原作裡的樣子 |
|---|---|
| 斜向的流與岸 | 流水與州浜斜穿畫面，從近景一路退到遠景，視線順著水往裡走。沒有水平切開畫面的直線 |
| 重疊遮擋 | 岩壓在水上，梅枝蓋過岩，霞截斷建築與樹。前後關係靠「誰蓋住誰」 |
| 技法分層＝距離分層 | 近景是高蒔繪加切金，最亮、最高；中景是肉合研出；遠景是研出或平蒔繪，平、對比低；最遠的天才是梨子地。隆起的高度本身就代表距離 |
| 尺度與密度遞減 | 越往上（越遠）東西越小、越疏、越淡 |
| 網點切金畫明暗 | 受光面片大而密，背光面漸疏（地已做，見 `MAKIE_GROUND_PLAN.md` D7） |
| 填隙 | 地上到處是極小的付描草花、小松、籬、葦手文字、家紋圓。梨子地只在天的部分大片露出，而且天上也有雲 |

## 2. 我們現在的問題

- 地標像「擺在桌上的模型」：南區的金堂、五重塔、三塊岩、兩棵松各自獨立，周圍是大片空的梨子地。
- 流水只是一條細線，沒有州浜、沒有斜向的岸把空間往後帶。
- 遠景層不存在：上半部是空的梨子地加兩條淡霞，看不出遠近。
- 霞只是細帶，沒有截斷任何東西。
- 前後物件幾乎不重疊。

## 3. 工作包

順序依「先量、再補地、最後動構圖」排。C1–C4 都畫在地上，平的、不立起，屬於「地」的工作，可以馬上開始；C5、C6 會改各區的構圖資料和部件位置，照使用者的順序等地定稿後再做。

| 包 | 內容 | 主要檔案 | 驗收 |
|---|---|---|---|
| C1 量留白 | 烘焙時從 ident map 算兩個數：**留白率**（蓋面上沒有任何部件、線、填隙的純梨子地比例）和**最大空白半徑**（離所有內容最遠的那一點有多遠）。寫進 `canvas.dataset`，十一區各量一次當基準 | `plate/bake.js`、`three-renderer.js` | 十一區的基準數字記在執行紀錄；之後每包都要讓數字下降 |
| C2 遠景研出層 | 上方三分之一自動生成遠山與樹林的剪影：平的研出、對比低，越上越淡，和梨子地交界用ぼかし。每區用自己的種子，山形不重複 | 新檔 `plate/distance.js`、`three-pack.js`（新 mat 或沿用 mura 的低對比版） | 截圖看得出近、中、遠三層；遠景不搶主題 |
| C3 付描填隙 | 在空的地上用 Poisson 圓盤取樣撒付描小景：草花、小松（初音的主題是正月子日的小松引き）、籬、零星梅花。**越下越大、越密、越亮，越上越小、越淡**，用密度梯度本身做出深度。離部件和水保持距離，不壓到主題 | 新檔 `plate/fillers.js`、`bake.js`（畫進線條通道） | 留白率降到 25% 以下；最大空白半徑降到現在的一半以下 |
| C4 天的雲 | 天的梨子地裡加濃梨子地的小雲與霞頭，不讓天變成一整塊平面 | `fillers.js` | 上方沒有大片純梨子地 |
| C5 霞切景與斜向州浜（地定稿後） | 霞加寬，故意截過建築基部與樹幹，讓主題「從霞裡浮出來」。流水兩岸加州浜，讓水斜向退到遠方 | 各區 `plate/*.js` | 每區至少一處霞遮擋、一條斜向退遠的岸線 |
| C6 各區構圖複查（地定稿後） | 逐區檢查斜向動線、重疊、近中遠技法分層；需要時移動部件、讓前後物件互相遮擋 | 各區 `plate/*.js` | 每區前後對照截圖 |

## 4. 驗收與限制

- 每包：十一區 1440px 日夜截圖，加上南區、北區、右京區的特寫；C1 的兩個數字要記錄。
- 效能：填隙全部烘進現有貼圖，不增加每幀的繪製呼叫；`bakeMs` 增量不超過 30%。
- 填隙不能變成雜訊：同一區的小景種類不超過三種，形狀要一眼認得出（草、松、籬），不是隨機筆觸。
- 這仍是 2.5D 浮雕，不是真 3D；深度靠技法分層與構圖，不靠移動相機。

## 7. 撤回隨機填隙（2026-11-14 晚）

使用者看線上版：「地現在是無差別亂塞，把原來的物、形意破壞了。」

錯在哪裡：把「留白率」當成目標，在空地上隨機撒草、松、梅、籬，再加上每區都一樣的遠山和雲。初音的小景沒有一個是隨機的，每一個都**屬於某個物**：草長在岸邊與坡腳，梅開在屋旁，籬圍著庭院，雲與霞在講距離。隨機填隙沒有「意」，只是雜訊，還和原本的物搶視線。

處理：C2、C3、C4 的隨機版全部移除（`fillers.js` 只留 `blankStats`）。留白率只當參考數字，不再當驗收目標。銀的暗面與銀岸（`MAKIE_GROUND_PLAN.md` D8）保留。

之後的做法（取代 §3 的 C2–C4，動手前先給使用者看）：
- **依附**：每個小景都要掛在一個物上，寫進該區的構圖資料，不再自動撒。例如：岸邊的草沿水線、坡腳的草沿土坡輪廓、梅在屋旁、籬接在建築之間。
- **少而準**：寧可少，也要每一個都說得出它屬於誰、在講什麼。
- **遠景與雲**照各區的地景個別設計（例如東山的山、嵐山的山），不用全區共用的生成器。
- 這些都會改各區的 `plate/*.js`，屬於 C5、C6，照使用者的順序等地定稿後再做。
